# Demo de Gestión de Compras e Importaciones

Versión `0.16.67-demo`. [Abrir demo](https://demo.naraconsultores.com/demo-app-importaciones-cp/).

Compilación pública con nombres reales de empresas y proveedores autorizados; operaciones y ejemplos simulados. Los cambios permanecen en la sesión del navegador y se reinician al recargar. JDE, Getpay, correo y documentos se simulan; esta demo no conecta con sistemas operativos. Su publicación no constituye aceptación funcional del cliente.
